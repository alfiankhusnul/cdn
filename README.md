# CDN PUBLIK

Repo ini digunakan untuk menyimpan aset publik yg digunakan pada beberapa project lain. Publik boleh juga menggunakan hasil repo ini.

Cara menggunakan adalah via layanan jsdelivr seperti berikut:
```
https://cdn.jsdelivr.net/gh/alfiankhusnul/cdn@main/{nama_lengkap_file_dengan_ekstensi}
```

Contoh untuk mengakses logo bps maka digunakan link aset sebagai berikut:
```
https://cdn.jsdelivr.net/gh/alfiankhusnul/cdn@main/logo_bps.webp
```
