# CDN Publik

Repositori ini menyimpan aset statis (logo dan gambar) yang digunakan di beberapa project saya. Aset dapat diakses oleh siapa saja melalui [jsDelivr](https://www.jsdelivr.com/), dengan memperhatikan bagian [Hak Penggunaan](#hak-penggunaan) di bawah.

## Cara Menggunakan

Cara menggunakan adalah via layanan jsdelivr seperti berikut:
```
https://cdn.jsdelivr.net/gh/alfiankhusnul/cdn@{kode_versi}/{nama_lengkap_file_dengan_ekstensi}
```

Contoh untuk mengakses logo bps maka digunakan link aset sebagai berikut:
```
https://cdn.jsdelivr.net/gh/alfiankhusnul/cdn@{v1.0.0}/logo_bps.webp
```

## Hak Penggunaan

Seluruh logo dan lambang di repo ini adalah milik pemiliknya masing-masing. Pengguna bertanggung jawab memastikan pemakaiannya sesuai peraturan yang berlaku.
